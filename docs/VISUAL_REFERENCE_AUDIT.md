## 本轮修复

- R／SR／SSR／BD／EX均使用各自游戏图标的透明裁切结果，等比例缩放后以实际可见宽高定位右下角。方形角色卡与横向留影卡沿用原稿各自的角标尺寸；列表、详情及活动／卡池／角色关联卡均使用同一锚定规则。排名的等级与觉醒标识仍保留其独立语义。
- 歌曲列表和榜线移除额外3600／4200像素页高限制，按既有图片像素、边长和字节预算判断是否拆图，保留完整行、曲目组和字号。
- 详情属性条恢复原稿固定显示比例：角色卡44000、留影卡45%对应完整条宽，不再按每张卡自身最大值归一化。超出条宽的数值保留完整标签，条形封顶；这只是显示比例，不是游戏数值上限。恢复延长时间／回复量行名，并给多条件队长技能的单行等级表标出对应条件。
- 续发测试显式设定会触发像素预算的输入条件，不再依赖额外页高限制；另验证超过3600像素但仍符合预算的歌曲列表保持单图。

## 验收范围

先检查实际代码、原稿和后续确认记录，再在服务器独立目录生成真实公开快照实图；长标题、缺图、长技能和合成边界另标数据性质。正式配置不可见、正式图片素材只读、网络关闭，不构造QQ客户端、不上传或发送。

榜线和谱面的既有公开缓存超过刷新时限时，视觉回放固定为其捕获时间，并保留原始响应、版本和载荷。此项证明固定公开快照的绘图，不证明当前实时榜分；冷／热缓存性能另外测量并说明素材及业务缓存条件。服务器产物绑定源码摘要，测试通过不代替实际图像对照。

激奏图标形状已有游戏原图；原稿中的着色仍为已注明的预览配色，准确游戏界面颜色未核实，不能写成已确认原色。
