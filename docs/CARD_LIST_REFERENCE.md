## 实现边界

`catalog_layout.render_list` 输入查询捕获的完整卡片集，不刷新资料。留影卡按完整角色组合分组，同一组合不受来源人物数组顺序影响；每张卡仅展示一次，不再拆到每个相关角色组。图块范围仍是连续展示位置，QQ准备层沿用该顺序生成选择编号。不改变查询筛选、卡牌ID和实际来源。

角色筛选通过 `characters` 参数传规范名，覆盖别名和组合条件；角色卡绘图限制展示组；留影卡使用已筛选的卡集，但完整保留每张卡的所有关联角色，包括跨乐队组合，不再查询人物。密度随实际结果变化：每名角色每种属性只有一张时，应为单列，不为了填满画布混排不同颜色。同色超过八张才换行。

角色卡仍使用原稿卡面与字体尺寸的两倍，保持比例。两类列表宽度均随同色最大列数变化，少量结果收掉空列。留影卡卡面保持288×162，列距348、技能24px，技能按完整文字测量行高；多人头像最多三列（五人为3＋2），姓名放在对应头像下方，长姓名完整换行。左栏合并当前页的同组行，若分组跨页则每页重新显示完整组标识；每个可独立分页的行均预留完整标识所需高度。缺人物元数据时保留已捕获的全部角色名。标题与状态页脚支持中英日换行。优先单图，超出1200万像素、8192边长或3MB才按完整行拆分，不为凑单图缩字。
