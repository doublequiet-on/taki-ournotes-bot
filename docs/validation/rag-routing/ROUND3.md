## 复跑与测量边界

在本评测工作树内执行，目标源码使用对应提交的干净 checkout。以下命令只读取公开题。首次运行产生可供后续版本逐题比较的报告，加 `--only D15 D20` 可单独重跑这两题。

```powershell
$python = '.\runtime\eval-venv\Scripts\python.exe'
$driver = 'docs/validation/rag-routing/run_behavior_v3.py'
& $python -I -B -X utf8 $driver --repo ../rag-eval-r2-base --output runtime/review3-base.json
& $python -I -B -X utf8 $driver --repo ../rag-eval-r2-initial --compare runtime/review3-base.json --output runtime/review3-initial.json
& $python -I -B -X utf8 $driver --repo ../rag-eval-r2-head --compare runtime/review3-base.json --controls --output runtime/review3-head.json
& $python -I -B -X utf8 $driver --repo ../rag-eval-r2-combined --compare runtime/review3-base.json --output runtime/review3-combo.json
```

旧报告记录 Python 和四项直接依赖的版本，驱动及题集文本的 SHA-256 均与受审提交相符。第三轮另记录已安装发行包名称和版本清单的摘要、可选样本的字节摘要和实际选择的题号。这些指纹可发现版本或输入漂移。它们不提供 Python 原生库、系统库或 wheel 的逐字节证明。

行为探针核实实际后端的单轮上限为 6 次模型调用、8 个工具操作、60 秒含最后 5 秒收束，并核对模型调用数、许可数及 D15 查读次数。D20 的两个独立会话分别计数。外部服务由本地夹具和模拟提供方替代。Python 审计钩子阻止对外连接、解析、数据报以及探针期间的子进程，允许 Windows asyncio 的标准库内部回环。六项合成审计事件验证相应拒绝路径，未发出网络请求。这是进程内措施，未测量操作系统级断网或第三方原生代码的网络行为。所得分数反映固定脚本能看到和准备发送的内容；真实模型选择、自然度、生产送达另需实测。
