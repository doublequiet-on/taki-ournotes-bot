## 迁移前需要另测的假设

- Hermes 试点的本地 relay 与对外 provider 是两段接口。本轮模拟 provider，没有启动 Hermes worker。若要迁移循环，应在相同外部 profile 和资料下比较冷启动、预热、取证完整性、取消后已出站费用结算，以及最终一次发送许可。保留同一请求预算、来源撤回和群作用域。
- 指定试点群续聊的 28 秒从入队起算。待测项包括高负载排队、切换路由和中途补充时原期限是否仍生效，以及旧结果能否阻止发送。显式聊天夹具只覆盖取消后的宿主行为。
- 主动路径还要以同一组“应接／跳过／等补充”标注分别比较时机、误接率与费用。决策后替换、延后及取消应核对同一机会预算，核对决策与生成的预留和迟到结算。真实误接率、自然度和节省的费用留待有授权的独立回放。
