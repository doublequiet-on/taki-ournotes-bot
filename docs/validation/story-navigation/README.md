# 爱音与立希羁绊第 1 话的离线导航试验

目录已经能利用人物和明确章节补齐证据。额外主题线索让 2 个可满足的请求从未命中变为能读回证据，也把一道卡面题误导向剧情。保留这个候选供离线复跑，当前证据适合继续用确定性目录导航。

## 固定输入

- 源码依赖 [PR #259](https://github.com/doublequiet-on/taki-ournotes-bot/pull/259) 的 `af66d87caad0caa24e417fdfe1867c921c682741`，其中 `StoryService.coverage()` 提供目前范围的目录。试验只使用本仓库的检索、目录和读回接口。
- 获准快照是 2026-10-30 本地交付稿 `story-bundle-complete.json`。解析哈希 `72df0d71d0acbae0f54c0473353dcd50057eb55733e7c86ad23f03222ba6618c` 与审核记录一致。镜像发布为 `r-01c9364ea529ce7e0f19`。快照包含 126 条来源、122 个场景。主题范围内有 1 条 `official_original` 日文短引和 1 场 `fan_analysis` 分析摘要，均为 `public_reference`。短引对应收到道谢后的末句，前后相邻句柄为空。全文、开头原台词和完整对答均缺。 [既有快照覆盖记录](../../STORY_SOURCE_COVERAGE.md#日服已审交付快照的覆盖复核2026-11-18)
- 用已公开的开发题「拿奶泡在杯面描图案」确认 A 和 B 都漏检。根据已批准短引的章节定位、标题和摘要主题制作 [candidate.json](candidate.json)。它只保存线索词、出处定位和版本，不含原台词或摘要正文。提交 `5c3c3293a98bc5276f803a649da5397391cc9bec` 冻结候选，规范 JSON SHA-256 为 `cdf617f6eda0b446cade28be7eb6aae4936743bf38df73edc4a30852bc829baf`。
- 冻结后编写 [R1–R10](cases.json)。D0 是开发题，从汇总排除。题目由本次执行者自拟，用于比较固定样例；独立保留题和实际群聊均未进入输入。期望证据层级用于评分，作品和章节范围由用例预先指定并同时传给 A、B、C。

## 对照方法

| 路线 | 做法 |
|---|---|
| A | 把问法直接交给现有词法与别名检索。每种来源层级至多命中 1 场，通过现有句柄读回。 |
| B | 先以相同范围读取覆盖目录。精确章节存在时直接使用；否则用现有别名改写和词法分词，章节标签有至少两个共同词项且唯一领先时缩小到该章，再检索和回读。目录无法定位时沿用 A。 |
| C | B 无法定位时试冻结候选。候选需获得主题词，或同时获得表示材料和图案的线索。先校验版本、范围及来源层级，定位后再通过同样接口读回短引与分析摘要。候选失效或拒绝时沿用 B。 |

统一预算是原作、分析与官方简介各最多命中和读回一场。问法和显式范围相同，目录查找额外读取元数据。评分区分检索到目标、读回目标原文或摘要、满足本题所需证据，以及跨范围或误导航。脚本输出场景 ID、来源层级判定和计数，生成台词数条目只记录本脚本行为。

## 复跑

在试验工作树根目录运行。用有权读取的本地审核交付稿代替占位路径。脚本校验冻结候选和 bundle 哈希，在工作树内创建并清理单独的临时版本目录。

```powershell
$env:PYTHONPATH='src'
$env:PYTHONIOENCODING='utf-8'
python -B docs/validation/story-navigation/replay.py --bundle '已获准的本地路径/story-bundle-complete.json'
```

重放同时断言以下生命周期。候选停用后拒绝导航，更换作品或章节后返回 `out_of_scope`。切换 bundle 版本后返回 `stale`。撤回原作短引后，候选和旧句柄均失效，回退 bundle 也不恢复。此时确定性目录只回读独立的分析摘要。
