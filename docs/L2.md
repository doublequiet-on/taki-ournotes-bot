# L2 Docs — 开发文档导航

## 职责与边界

本目录保存开发任务索引、当前机制专题以及设计／发布记录。本页帮助选择文档，不重复源码架构、操作命令或阶段状态；不增加 L2-2。

阅读时区分当前导航、专题约定与历史依据。历史文档中的路径、分支和验证结果需要结合当前实现核对，不能直接当作现状；明确的产品要求也不能仅因文档较早就删除。

## 与其他文档的分工

- 用户能力、用法与路线图由 [README](../README.md)维护；阶段状态见 [交接文档](../交接文档.md)。
- 源码职责从 [开发导航](DEV_GUIDE.md)进入相应 src 地图和文件头；测试分组见 [Tests L2](../tests/L2.md)。
- 准备与启动边界见 [Deploy](../deploy/L2.md)，仓库工具及部署状态协议见 [Scripts](../scripts/L2.md)。
- QQ 人工接入与验收见 [LOCAL_QQ_TEST](../LOCAL_QQ_TEST.md)，更新和公告的操作／排查见 [自动更新说明](../自动更新说明.md)。
- 来源与素材边界见 [THIRD_PARTY](../THIRD_PARTY.md)，别名维护见 [昵称词表维护规范](../昵称词表维护规范.md)。

同一事实在对应文档维护，其他入口用摘要和链接引用。更新当前机制时同步相关导航，不改写历史记录来伪装为最新说明，也不复制一份实时参数表。

## 维护与检查

新增或调整文档时核对相对路径、锚点、符号及其实际职责；新文件需检查正文，不能只看普通 Git diff。纯文档修改不启动机器人、同步或部署。Git 仓库中的文档存在不代表已进入发行包，收录规则以 [MANIFEST.in](../MANIFEST.in)为准。
