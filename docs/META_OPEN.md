# Moenotes 可选开放平台

歌曲分数表已移除；本文件仅描述仍保留的 open 榜线来源。

## 正式榜线合同与认证门槛

```text
GET https://bdon.moe/api/open/v1/moenotes/{region}/event/challenge-ranking?challengeMusicId=<十进制字符串>
Authorization: Bearer <安全配置的Secret>
```

只请求具体challenge operation，不附eventId／musicId／排名区间；一次读取后本地裁切原Top100、附近十名、闭区间、离散点。`hk→tw`和日服默认不变。数字ID保留前导零／长整数，用户名来自同条记录；profileId不替代玩家数字ID。protobuf JSON经过形状校验的对象行可省略score表示0，显式null／非法类型／空洞仍未知；旧tracker缓存不套此解释。

正式源只消费`X-Moenotes-Fetched-At`为源时刻；Unix毫秒合同需认证验证。HTTP Date仅在与接收时钟足够接近时作为可信年龄参考，不代替源时间。当前fresh120秒、过期600秒及同源旧缓存边界保留；时间头缺失或参考时钟不可信隐藏当前分数及附属身份、不写有效历史点；异常观测保留质量和缺口。结束后只称最后获取，非确认终榜或tracker最后观测。切期／映射变化丢弃不可靠结果，原位置不挪动。

认证与匿名请求分开session，固定目标、禁止重定向，Secret不进入URL／repr／CDN／异常正文／缓存／历史／QQ。本地最多3个共享外网槽、总截止时间、有界查询队列和同榜请求合并；正式网关远端缓存命中也按实际合同计调用。

| 故障 | 行为 |
|---|---|
| 401／403 | 安全认证／权限状态，停止重复请求直到Secret配置变化 |
| 404 | 本资源不存在或不支持，保持请求身份，不自动改接口 |
| 429 | 尊重Retry-After，共享冷却，记录失采，不无限积压 |
| 网络／502／503／504 | 总截止时间内至多一次适合的重试；503维护、上游认证／会话／版本异常分别标识 |
| 坏响应、未知时间、身份变化 | 不发布可信当前值或有效历史点；同源旧缓存按边界明确展示 |

本地保守分钟窗口100次，不代表远端SLA；catalog与前端通用文档存在分钟／并发差异，实际跨应用共享及远端计数需认证确认。调用累计仅观测，无每日总量拒绝、无日重置、不缩四服、不降低原采样频率。当前12挑战×每日288轮=3456次排名请求是容量模型，非生产报告；公开发现仍独立。维护者确认文档日额度不是实际总量限制，此项不作为迁移阻塞。

上线开关之前必须通过真实小规模认证验收：四服与挑战身份、完整Top100能力（与参与人数不足分开）、分数／ID／姓名原位关联、时间头透传／单位／缓存原时刻、可信参考时钟、分钟共享／并发／429／维护恢复。离线100位置样例及调用计数测试不能证明远端覆盖。无安全配置 Secret 时，真实认证验收保持未完成；不要求将 Secret 贴到聊天。
