# 人格研究与统一审核记录格式

此文件提供 K1b 的研究记录格式，不是审核通过的人格正文。运行初稿继续保留 `legacy-derived`，本批不自动批准任何新内容。

每个候选判断应记录：

| 字段 | 填写要求 |
|---|---|
| 判断 ID／版本 | 稳定 ID 与可回退版本，修正时保留被替代关系。 |
| 判断内容 | 具体的价值取向、关心方式、急躁触发条件或改变判断所需依据，避免只写“很凶”等标签。 |
| 适用剧情时点 | 明确作品、改编版本、故事阶段；未知保持空。后发表回忆不等于最新状态。 |
| 支持场景 | 发布 revision、scene_id、说话者与原文定位，能通过 story_read 回读整段交流。 |
| 反例与情境 | 至少核对关系、压力、前后语境；不能把单次冲突写成永久敌意。 |
| 来源层级 | 日文原文、既有译文、官方简介、玩家解读分别记录；解读写作推断。 |
| 研究结果 | 原作事实与派生分析分开，标记 draft，不直接进入运行提示词。 |
| 人工审核 | 接受／修改／暂留及理由；reviewer、reviewed_at、confirmation_ref，审核范围绑定源 revision。 |
| 运行稿 | 审核后提炼少量稳定行为原则，不按场景拼贴台词，不为群聊投票写永久喜好。 |

发布前核对：所有判断可追溯、反例已检查、未撤回、来源使用范围允许、没有跨版本混同。人工确定接受后，才从可信本地 operator 调用 `approve_persona`。导入 bundle 中的 approved 标签不能代替这个动作。

运行中全群共享同一已批准人格版本；各群对话记忆不改变此发布指针。切换剧情语料版本后，旧批准不自动套到新内容；必要时先回到旧 `legacy-derived` 初稿，完成审核再切换。撤回人格或其依据后，运行稿不可用；代码或语料回退不复活撤回内容。
