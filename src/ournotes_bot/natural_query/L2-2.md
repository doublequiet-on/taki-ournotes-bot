# L2-2 Natural Query

## Purpose

把自然语言限制在可验证的查询能力内，管理从本地解析、有限模型请求到明确终态的全过程。多个文件共同实现同一信任/预算边界，足以独立成子域。

## Position inside parent L2

属于 [Query](../../L2-Query.md) 的问题解释面。返回可信结果的事实来源仍为 Deterministic 和 Data；不建立第二套游戏知识库。

## Inputs

原始问题、仓库/别名、能力目录、可选 requester、额度/指标及时间策略。

## Outputs

`AIQueryParser.answer_with_plan` 输出 `(text, QueryResult | CommandResult | None)`；
`answer_with_outcome` 输出 `AgentOutcome`，携带结果与状态/终态。模型响应本身不成为游戏答案。

## Core Flow

检查输入与来源指纹 → 命中计划/终态缓存或本地命令/语法 → 必要时选能力 → 受限模型动作 → schema、实体及原文条件校验 → 确定性执行。
活动歌曲榜线在通用缓存与旧拒绝词判断前由 `parse_natural_cutoff` 识别，本地执行且不访问模型／额度／通用终态缓存；预测、配队、账号操作等仍拒绝。`event.cutoff` 仅为本地执行契约，不暴露给模型路由。相关解析与源状态均由 [Deterministic](../query/L2-2.md) 专项结果提供。
仅在规定的可修复错误下再请求一次修复，且受总时间和调用数限制；空结果不触发放宽条件。缓存计划再执行时读取当前数据，不等于永久缓存事实答案。

## Dependencies

[Deterministic](../query/L2-2.md) 的契约、执行器、实体和词法；Data 仓库；Application AIClient。
`ai_query.py` 组装客户端、DailyQuota、QueryMetrics 和 QueryAgent，main/QQ 通过它进入。

## Boundary with sibling L2-2 modules

Natural 的 local_query 与 validation 共享自然语言判断；Deterministic 管可执行条件语义。Natural 不复制结果筛选器、不拥有通用 AI 传输。
发布通知虽然同用 AIClient，但不复用本域的配额、指标、问句缓存或提示。

## Relevant Tests

- [test_query_refactor.py](../../../tests/test_query_refactor.py)：三次模型请求上限、一次修复、时间预算、空结果终态、慢模型不锁住本地查询。
- [test_natural_query_eval.py](../../../tests/test_natural_query_eval.py)：路由/校验/执行与原文条件锚定；测试名称 L1/L2/L3 不是 GEB 层级。
- [test_stage5_limits.py](../../../tests/test_stage5_limits.py)：额度先持久预占，记录损坏时关闭模型调用。
- [test_query_debug.py](../../../tests/test_query_debug.py)、[test_observability.py](../../../tests/test_observability.py)：有用查询计数、日志不保存问句正文；持久指标分类还见 test_query_refactor。
- [test_ai_lexicon.py](../../../tests/test_ai_lexicon.py)：不能替换原文实体或偷带条件。

## 当前实现与边界

八个内部实现位于 natural_query/；ai_query.py 继续作为原入口组装它们。额度与指标各实例的线程锁不代表多进程协调；额度故障关闭模型调用，指标故障停记，debug 仅进程内。校验和本地解析对 commands 私有帮助的现有引用保留，不抽共享契约。
