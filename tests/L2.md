# L2 Tests — 自动化验证导航

## 职责与边界

本目录用 `unittest` 验证查询、资料、渲染、QQ 接线和更新器的行为契约，使用测试桩、固定样例及临时数据。测试按验证对象组织，可能跨多个源码域，不要求与源码目录一一对应。

这里提供选测入口，不重复业务设计或运行命令，不增加 L2-2。测试通过不证明真实 QQ 送达、上游数据可用、付费模型效果或 Windows 生产部署正常。

## 验证方式与依赖

- 执行环境、凭据隔离、单文件选择及完整回归命令统一见 [开发指南：开发与验证命令](../docs/DEV_GUIDE.md#开发与验证命令)。优先选择受改动影响的测试，共享接口或跨模块行为变更再扩大范围。
- 测试依赖项目代码及相关运行依赖；绘图检查需要可用字体，部分边界测试使用独立进程。离线测试不等于无文件写入，临时目录和子进程属于用例的一部分。
- CI 调度及构建入口见 [checks.yml](../.github/workflows/checks.yml)；发布归档内容检查由 [check_release_artifact.py](../scripts/check_release_artifact.py)执行，不等同本目录所有测试的覆盖。
- 图片样式仍需按 [Rendering 地图](../src/L2-Rendering.md)与开发指南做人工预览；真实 QQ 验收见 [LOCAL_QQ_TEST](../LOCAL_QQ_TEST.md)，更新／通知操作见 [自动更新说明](../自动更新说明.md)。
