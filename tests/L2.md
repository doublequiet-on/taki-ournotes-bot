# L2 Tests — 自动化验证导航


## 职责与边界

本目录用 `unittest` 验证查询、资料、渲染、QQ 接线和更新器的行为契约，使用测试桩、固定样例及临时数据。测试按验证对象组织，可能跨多个源码域，不要求与源码目录一一对应。

这里提供选测入口，不重复业务设计或运行命令，不增加 L2-2。测试通过不证明真实 QQ 送达、上游数据可用、付费模型效果或 Windows 生产部署正常。

## 验证方式与依赖

议题 #40 的恢复回归位于 `test_query.py`、`test_card_catalog.py`、`test_visuals.py` 和 `test_linux_backend.py`：覆盖 HTTP 中断的缓存降级、过期冷启动保留两类技能、坏素材有限重取与原子写入、筛选顺序及真正未知候选、CI 临时故障不污染永久失败清单。

- 执行环境、凭据隔离、单文件选择及完整回归命令统一见 [开发指南：开发与验证命令](../docs/DEV_GUIDE.md#开发与验证命令)。优先选择受改动影响的测试，共享接口或跨模块行为变更再扩大范围。
- 测试依赖项目代码及相关运行依赖；绘图检查需要可用字体，部分边界测试使用独立进程。离线测试不等于无文件写入，临时目录和子进程属于用例的一部分。
- CI 调度及构建入口见 [checks.yml](../.github/workflows/checks.yml)；发布归档内容检查由 [check_release_artifact.py](../scripts/check_release_artifact.py)执行，不等同本目录所有测试的覆盖。
- 图片样式仍需按 [Rendering 地图](../src/L2-Rendering.md)与开发指南做人工预览；真实 QQ 验收见 [LOCAL_QQ_TEST](../LOCAL_QQ_TEST.md)，更新／通知操作见 [自动更新说明](../自动更新说明.md)。

向上阅读：[仓库 L1](../L1.md)、[开发规则](../AGENTS.md)、[任务与源码导航](../docs/DEV_GUIDE.md)。新增或改动测试时维护相关分组，不在本页记录测试数量或阶段通过状态。

## Linux 离线更新验证

`test_linux_updater.py` 用故障注入验证持久事务、跨进程网络退避与恢复、其他准备故障的有限重试、旧进程保护及回退；`test_linux_backend.py` 验证隔离命令、精确 CI、兼容门禁、离线安装调用和不写状态／不操作服务的中文进度；`test_offline_bundle.py` 验证归档路径、摘要、断点缓存、官方线路回退、Range 错误、签名过期和下载故障；`test_offline_release_build.py` 验证工作目录未跟踪源码和旧构建文件不能混入提交专属安装包。真实 Linux 断网安装由 Checks 的 `offline-linux-bundle` 运行 `scripts/check_offline_release.py`，不能用 Windows 跳过的 POSIX 用例替代。

[test_removed_score_table.py](test_removed_score_table.py)：退役命令、菜单、自然语言与源构造验收；[test_catalog_concurrency.py](test_catalog_concurrency.py)：刷新 I/O、完整发布、目录捕获与续查版本一致读取。

谱面与属性：`test_chart_data.py`、`test_haneoka_charts.py`、`test_song_traits.py`；成员资料 `test_haneoka_members.py`；open 榜线 `test_moenotes_open.py`；活动静态身份 `test_haneoka_event_metadata.py`；下载调用链 `test_source_egress.py`。

统一美工／单图优先：`test_readable_pages.py`、`test_single_image_upgrade.py`、`test_visual_upgrade_contracts.py`，覆盖完整分段、快照续发、角标事实、缓存所有权与失败回退。

ON 词法与字段验收：[test_on_language.py](test_on_language.py)，固定问句见 [on_language.json](fixtures/on_language.json)。

词库加载回归：[test_alias_loading.py](test_alias_loading.py) 覆盖坏文件、删除/读失败、恢复、路径隔离、同 mtime 内容变化、并发读取；[test_query_spec.py](test_query_spec.py) 补 SNAP 缩写入口、目标核实、缓存版本和口语多选的零模型/额度样例。

短名与角色单字选择器：[test_short_names.py](test_short_names.py)，覆盖乐队别名、汉字消歧、原文边界及旧译名目标。

别名证据与入口一致性：[test_alias_evidence.py](test_alias_evidence.py)。
## 知识库工程验证

`test_platform_boundary.py` 覆盖禁网空库、批准集合、删除／重启失效与范围；`test_console_policies.py` 覆盖后端组合和独立观察任务，`test_install_paths.py` 覆盖配置路径。真实正文效果与 QQ 回答不由这些合成夹具证明。见 [包 2B](../docs/QUERY_CHAT_PACKAGE2B.md)。
